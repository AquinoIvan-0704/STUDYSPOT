# StudySpot 📚

StudySpot is a full-stack Node.js and Express web application designed to help users discover quiet and comfortable study spaces, libraries, and cafes in their community. It features user authentication, a dynamic multi-page navigation interface, and an interactive search tool.

---

## Prerequisites & Installation

Before running this project locally, ensure you have **Node.js** (which includes npm) installed on your computer.

### 1. Download and Install Node.js
If you don't have Node.js installed:
* **Windows / Mac / Linux:** Go to the [Official Node.js Website](https://nodejs.org/) and download the **LTS (Long Term Support)** version.
* Run the installer and follow the setup wizard.
* Verify the installation by opening your terminal or command prompt and running:
  ```bash
  node -v
  npm -v
npm install
node server.js
